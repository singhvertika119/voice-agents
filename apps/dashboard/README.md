# Dashboard

The website for workspace owners: agents, knowledge, tools, calls and settings. Next.js on Vercel.

- Run locally: `npm run dev` (reads the repository root `.env`), then open http://localhost:3000.
- Checks: `npx tsc --noEmit`, `npm run lint`, `npm test`.
- Setup, database migrations and deployment: see the repository root `README.md` and `docs/deployment.md`.
